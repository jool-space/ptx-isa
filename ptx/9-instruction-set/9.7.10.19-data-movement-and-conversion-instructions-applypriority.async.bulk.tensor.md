#### 9.7.10.19. Data Movement and Conversion Instructions: applypriority.async.bulk.tensor


`applypriority.async.bulk.tensor`


Apply the cache eviction priority to the specified tensor address in the specified cache level.


Syntax


    applypriority.async.bulk.tensor.dim{.src}.completion_mechansim{.load_mode}
       .level::eviction_priority{.override::global_address}{.override_attribute}
       [tensorMap{, gAddrToOverride}{, attributeOverrideInfo}, tensorCoords]{, im2colInfo};
    
    .dim = { .1d, .2d, .3d, .4d, .5d };
    .level::eviction_priority = { .L2::evict_normal };
    .src = { .global };
    .override_attribute = { .override::global_dim_stride, .override::global_dim };
    .completion_mechanism = { .bulk_group };
    .load_mode = { .tile, .tile::gather4, .im2col,
                   .im2col::w, .im2col::w::128 };
    


Description


The `applypriority.async.bulk.tensor` instruction applies the cache eviction priority to the tensor. Qualifier `.level::eviction_priority` specifies the priority and the cache level.


If no state space is specified then Generic Addressing is used. If the specified address does not fall within the address window of `.global` state space then the behavior is undefined.


Various tensor attributes such as the base address and size of the tensor are specified in the Tensor-map.


The optional qualifiers `.override::global_address` and `.override_attribute` supports value override functionality for various tensor properties present in the `tensorMap` object. For more details refer Overriding tensor property value.


The qualifier `.bulk_group` specifies that the `applypriority.async.bulk.tensor` variant uses bulk async-group based completion mechanism.


The `applypriority.async.bulk.tensor` instruction is treated as a weak memory operation in the Memory Consistency Model.


PTX ISA Notes


Support for `applypriority.async.bulk.tensor` introduced in PTX ISA version 9.4.


Target ISA Notes


Supported on the following family-specific architectures:


  * `sm_107f` or higher in the same family


Examples


    applypriority.async.bulk.tensor.1d.global.bulk_group.L2::evict_normal [tensorDesc,{u}];
    applypriority.async.bulk.tensor.2d.global.bulk_group.tile.L2::evict_normal [tensorDesc, {u, v}];
